Release notes

Changes that actually affect this website, its data and local game edition.

Source checked · b29708914 Oct 2026

14 October 2026 — Initial source-checked edition

Pinned game revision b29708900da26b34e70d2dc07ad1659a719f4a78. Imported 966 available Pokémon and 64 moves. Added local solo packaging, persistent guest progression, eight guides and planning tools.

What differs from upstream

This copy disables cloud configuration, online entry points, automatic updating and Service Worker registration. Guest progression persists locally; the upstream guest mode is memory-only. Original gameplay rules are preserved.

Verification status

Source-level checks and automated validation are recorded with the project. Browser playtesting, real-device behavior, original-save migration and production delivery require separate acceptance. This entry does not claim that the site is already deployed.
