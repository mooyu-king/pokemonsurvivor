Tickets, banners & pity

Gacha spends tickets earned in play. This release has nine regional banners with a separate pity counter for each. The code guarantees a five-star rarity when that banner’s counter reaches 70, not after 70 additional unsuccessful pulls.

Where do tickets come from?

Ordinary non-boss enemies have a 1/400 normal-ticket drop roll. Ordinary bosses have a 1/3 chance to drop a ×10 ticket. Rift legends drop three normal tickets and have a 1/2 chance for a ×10 ticket. These are separate from progression rewards, and drops must be collected.

Should I switch regions to finish pity?

Switch to find a species in that region, not to combine pity. Each banner has its own counter. A five-star pull resets that banner; the guarantee does not select a particular Pokémon.

Is the tenth pull always five stars?

No. When the first nine contain no four- or five-star result, the tenth guarantees at least four stars, subject to pool fallback. The separate 70-counter rule governs five-star pity.

In the local game

Actual desktop browser captures from this local edition, 14 October 2026. Open an image for a larger view.

01

Earn and spend tickets

A single pull costs one normal ticket. Ten pulls use ten normal tickets or one ×10 ticket, selected in the game. Enemy rewards, bosses and progression rewards can provide tickets. There is no ticket purchase system in this local edition.

02

Understand rarity weights

The base weights are 45% for one star, 30% for two, 17% for three, 6.5% for four and 1.5% for five. These are rarity weights, not the probability of a particular species. Empty rarity pools can fall back to a nearby populated rarity.

03

Count pity per banner

The code increments the counter before testing it against 70. A five-star result resets that banner’s counter. Switching from Kanto to another region does not combine counters. A specific five-star species is never guaranteed by this counter.

04

What ten pulls guarantee

If the first nine pulls contain no four- or five-star result, the final pull rolls from four stars and above, subject to the pool fallback. A ten-pull ticket changes payment, not the basic identity of the banner.

05

Separate shiny odds

The shiny roll starts at 1 in 100, provided a shiny sprite exists. Duplicate shiny handling may select another missing shiny of the same rarity, or fall back to normal if all are owned. Do not treat that base roll as a fixed 1% chance for a particular shiny species.

Common mistakes & limits

  • A rarity probability is not a species probability.
  • Counters belong to each region.
  • The README wording about pity differs from the executable condition; this guide follows the fixed source.
