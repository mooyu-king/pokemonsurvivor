Rules: fixed game revision b297089. coop.js

01

Use the correct edition

The original game supports online friends and co-op through its own services. Those services are not ours. We do not reuse the author’s Firebase project, ask for the original account password or transfer player records.

02

Start at the author’s site

Open pokesurvivor.com in a separate tab. Follow its current login process, add a friend by nickname and use its invite flow. The author describes groups of up to four, shared experience and reviving nearby fallen teammates. Availability depends on their current service.

03

Keep saves separate

Local progress on pokemonsurvivor.wiki is not a cloud account. A wiki build link shares a planning configuration only, not collected characters, tickets or a running multiplayer session.

04

When a lobby fails

On the original service, check that friends are using the same version and review the author’s current help. This website cannot diagnose or reset an account on another operator’s backend.

Common mistakes & limits

  • There is no hidden multiplayer switch in this local edition.
  • A planner share link is not a lobby invite.
  • Do not enter another website’s password into a wiki tool.
