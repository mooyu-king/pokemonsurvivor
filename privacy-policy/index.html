Privacy Policy

How this website handles local game progress, wiki builds, analytics and external links.

Source checked · b29708914 Oct 2026

Game hosting and separate saves

The embedded game is hosted on s.pokemonsurvivor.wiki. Game progression is stored in that origin’s browser storage; wiki builds stay on pokemonsurvivor.wiki. Older game saves on the main domain remain at the older game entry in our save guide and are not automatically migrated. Browsers may further separate game storage when embedded on partner websites. No game save is sent to a server by this edition.

Last updated: 14 October 2026. This policy describes the features in this website’s initial local edition.

Local game and wiki storage

The game stores collection and progression in your browser under game-specific keys, including ps.local.guest.v1. Wiki drafts use pswiki:v1:builds; owned markers use pswiki:v1:favorites. These are separate from game saves. They are not automatically uploaded by the tools. Clearing site data, using private browsing or moving to another origin can remove or separate them.

No cloud account

This edition disables original-game cloud login, friends and leaderboards. We do not ask for your original game password or access the author’s player database. Local storage is not cross-device synchronization.

Traffic analytics and hosting

The site loads a traffic analytics script from data.1back.link/js/app.js and sends requests to data.1back.link/api/send for pokemonsurvivor.wiki. These requests may include ordinary network and browser information such as IP address, page address, referring page and device information. Hosting providers also process technical requests to deliver files. We do not intentionally send game saves, passwords, build names or share-fragment contents as custom analytics fields.

Exports and share links

A build link includes its planning configuration and name in the URL fragment. Anyone receiving it can read that configuration, so do not use a private name or secret. JSON exports contain wiki drafts and owned markers; they are not game backups. Import processing happens in your browser.

External links and contact

Following a source or author link takes you to another operator with its own policy. Emailing us voluntarily shares your email address and message. Do not send passwords, account tokens or private game files. We use correspondence to respond to the request.

Your choices

Use Saved to export or remove only wiki data. Browser controls can remove all site data, but doing so can erase game progress. Analytics may be blocked by privacy tools. For a privacy inquiry, contact mooyuking@gmail.com. This policy will be updated if actual services change.
